계정 및 데이터 삭제 안내

“라이프플래너 - 경건에 이르는 훈련”의 계정과 데이터를 삭제하는 방법입니다.

앱에서 직접 삭제하기

앱 실행 → ‘계정’ 탭 → 회원 탈퇴를 선택하고 비밀번호를 다시 입력하면 계정과 모든 기록이 즉시 영구 삭제됩니다.
계정은 유지한 채 기록만 지우려면 ‘계정’ 탭의 전체 데이터 초기화를 이용하세요.

이메일로 삭제 요청하기

앱에 접속할 수 없는 경우, 가입한 이메일 주소로 아래 문의처에 삭제를 요청해 주세요. 본인 확인 후 지체 없이 처리합니다.

문의: kimsketch@naver.com

삭제되는 데이터

  • 계정 정보(이메일 주소)
  • 성경읽기 진도, 성경암송 카드 및 암송 테스트 기록
  • 묵상노트, 기도노트, 교제노트, 감사노트
  • 직접 붙여넣은 성경 본문, 시간대 설정
  • 캘린더 일정·할 일, 포인트·배지 기록

삭제된 데이터는 복구할 수 없으며, 별도로 보관하지 않습니다.

개인정보 처리에 관한 자세한 내용은 개인정보처리방침을 확인해 주세요.
